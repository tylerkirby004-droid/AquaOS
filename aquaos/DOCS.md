# AquaOS

After installation, start AquaOS and enable **Start on boot**, **Watchdog**, and
**Show in sidebar**. Open **AquaOS** in the Home Assistant sidebar. Home
Assistant authenticates the panel; AquaOS does not ask for another code.

The first start is simulator-only. Keep aquarium equipment disconnected until
the guided commissioning checks and independent physical safeguards are in
place. This development build is not approved for live livestock control.

Configuration and backups are included in Home Assistant backups through the
app's private configuration directory.
