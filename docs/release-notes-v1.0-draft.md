# AquaOS Core v1.0.0 release notes — DRAFT / NOT RELEASED

This draft does not authorize livestock use. AquaOS remains pre-release until
every release-candidate checklist item passes and a maintainer approves v1.0.

The candidate includes native Control VM services, deterministic policy,
registries, state, alarms, REST/MQTT v1, direct-LAN boundaries, Home Assistant,
optional persistence, recovery tooling, an embedded non-authoritative Admin
GUI, and the removable `aquaos-vision` scaffold.

Release blockers are incomplete lamp-load, clean-VM, Proxmox maintenance,
replacement-host restore, security-CI, and 72-hour soak evidence. Physical
Proxmox host loss stops Core. Independent physical safeguards remain mandatory.
Never use AI, dashboards, MQTT, or AquaOS as the sole protection against
overheating, overflow, electrical faults, or loss of life support.
